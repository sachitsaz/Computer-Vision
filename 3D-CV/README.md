# 🧊 3D Computer Vision

This section contains my 3D computer vision projects and experiments, focusing on depth estimation, depth-map analysis, and 3D scene understanding.

## 📂 Projects

### 🔹 [Depth Anything V2](./01_Depth_Anything/)

Monocular depth estimation, quantitative model comparison, video depth visualization, and a proximity warning system using depth estimation.

- **Depth estimation:** Single-image and video depth prediction.
- **Model comparison:** Evaluation of Depth Anything V2 Small and Base.
- **Proximity warning:** Identifying potentially nearby objects using estimated depth.
- **Reports and results:** Experimental reports, quantitative results, and visualizations.
